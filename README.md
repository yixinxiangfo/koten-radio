# 古典と歴史の朗読ラジオ

古典文学と歴史を、やさしい語りで楽しむ日本語の朗読番組です。
家族のために、横になったまま聴けるようにと作りました。

**▶ 聴く：** （GitHub Pages の公開URLをここに入れる）

## 番組
| | 番組 | 内容 |
|---|---|---|
| 1 | 更級日記 | 物語に恋した少女の一生。源氏物語に夢中になった平安の文学少女の日記 |
| 2 | 伊勢物語 | 和歌を中心に、歌が生まれた場面とともに味わう |
| 3 | 枕草子 | 清少納言の感性と、宮廷の暮らし |
| 4 | 北条早雲 | 戦国大名・後北条氏を起こした人物の生涯 |

1本あたり2〜3時間。約10分ずつに区切ってあり、続けて自動で再生されます。

## 聴き方
- スマホでリンクを開いて、再生ボタンを押すだけです。アプリやダウンロードは要りません
- 前回の続きから再生できます
- 再生速度の変更と、おやすみタイマー（30分・60分）があります

## 作り方
- 台本：Claude（Anthropic）が執筆
- 音声：Gemini TTS（Google）による合成音声
- 再生ページ：HTML 1枚の静的サイトを GitHub Pages で公開

## 著作権について
- 古典の原文はパブリックドメインです
- 現代語訳と解説は、この番組のために書き下ろしたものです。既存の現代語訳や小説の文章は使っていません
- 歴史の回では、史実と伝説・言い伝えを区別して紹介しています

## フォルダ構成
```
scripts/      台本（10分ごとのブロック）
audio/        音声（MP3）
tts/          音声化プログラム
episodes.json 番組の一覧
index.html    再生ページ
```

※ APIキーは環境変数で管理し、このリポジトリには含めていません。
